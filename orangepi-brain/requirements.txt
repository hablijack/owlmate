# Robot Owl OrangePi Brain - Python dependencies
#
# Compared to the RPi brain, the OrangePi drops the torch/CTranslate2 stack
# (opencv-python-headless, soundfile, faster-whisper, ctranslate2). Speech is
# Vosk (streaming ASR, default) or whisper.cpp; the sentence -> mood model runs on
# onnxruntime. All are imported lazily (only when their feature is enabled), so
# the brain still starts on a machine where they are absent.
pyserial>=3.5
numpy>=1.24.0
pyyaml>=6.0
flask>=3.0.0
# Audio (MAX98357A I2S amp): playback via ALSA 'aplay'; WAV built with stdlib
# (wave + struct). No extra Python package required -- 'aplay' ships with the
# OS (alsa-utils). The amp and the mic share ONE I2S card (I2S0), so the same
# card is used for playback here and capture in speech.py.
#
# Speech recognition (ICS43434 I2S mic -> offline whisper.cpp ASR). Imported
# lazily by brain/speech.py ONLY when speech.enabled is true, so the brain still
# runs on a machine with no mic and the heavy ASR import stays out of normal
# startup. 'sounddevice' needs the PortAudio system library (installed by
# setup.sh). The mic is captured at the card's native 48 kHz / stereo and
# resampled to 16 kHz in the worker before the VAD + ASR.
sounddevice>=0.4.6
# Default ASR engine is Vosk (speech.engine: vosk): Kaldi, streaming, ~0.2 s from
# end of speech to text on the Zero 3W, and it hears "Hubert" (specs/014 has the
# comparison against whisper tiny/base/small/medium/turbo). The model is a LOCAL
# directory downloaded by setup.sh (speech.vosk_model) -- the OrangePi runs offline.
vosk>=0.3.45
# Alternative engine (speech.engine: whisper): whisper.cpp via pywhispercpp, no
# torch / CTranslate2. Its model is a LOCAL .bin (speech.model).
pywhispercpp>=1.5,<2
# Sentence -> mood (brain/mood.py, mood.enabled): a fine-tuned multilingual MiniLM
# exported to int8 ONNX by tools/train_mood.py on a dev machine. The Pi needs only
# the runtime and the tokenizer, no torch. Imported lazily.
onnxruntime>=1.17
tokenizers>=0.15
